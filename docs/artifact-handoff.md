# 测试资料与交接

tester 直接读取 Jira 中的需求、验收及关联文档，通过当前可用的 Jira、文档或代码 MCP 获取本次所需内容。用户提供的材料与本地文件同样可用；只记录实际来源和被测版本，不要求准备独立资料仓库。

正式验证交付测试范围、方法、真实结果、失败证据、未覆盖项和结论。单次简单检查可以直接回复。

| 内容 | 位置 |
| --- | --- |
| 计划、报告、复现记录 | 沿用项目位置；无约定时用 `docs/tester/<feature-id>/` |
| 日志、截图、trace 等证据 | 沿用 runner、CI 或项目证据位置，报告提供可访问链接 |
| 测试代码、fixture 与配置 | 工程已有测试目录 |

已有文件原位维护，不要求迁移历史文档。按任务需要把测试计划、结果或缺陷证据关联到已有 Jira 工单；写入与回读见 [e2e-sync-test-cases](../skills/e2e-sync-test-cases/SKILL.md)。有工单本身不触发新建子任务。

未运行不能记为通过，无法访问或保存的证据明确说明。详细要求见 [测试交付与证据](../skills/e2e-workflow/references/delivery.md)。
